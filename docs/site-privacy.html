Данные посетителей сайта

Эта страница относится к лендингу Impuls на GitHub Pages. Обработка данных внутри приложения описана отдельно в публичной модели приватности проекта.

Что действует сейчас

Лендинг не содержит форм регистрации, личного кабинета, встроенной аналитики, рекламных пикселей или собственных cookie. Нажатие кнопки скачивания переводит на файл релиза в GitHub.

Технические журналы GitHub Pages

Сайт размещён на GitHub Pages. GitHub может обрабатывать стандартные технические данные запроса — например, IP-адрес, тип браузера и время обращения — в соответствии со своей политикой конфиденциальности и правилами работы сервиса.

Готовность к рекламной аналитике

В коде лендинга предусмотрены локальные события для кликов по скачиванию, GitHub, обратной связи и вопросам. Пока внешний счётчик не подключён, эти события никуда не передаются.

Если Яндекс Метрика, Google Tag Manager или другой сервис измерения будет активирован, до запуска будут выполнены три действия:

  • эта страница будет дополнена точным перечнем сервисов и данных;
  • необязательные технологии будут подключаться с учётом применимых требований к уведомлению и согласию;
  • сроки хранения и порядок отказа будут указаны явно.

Приложение Impuls

Буфер обмена, заметки, заготовки, файлы и календарь обрабатываются локально на Mac. Необязательная проверка обновлений обращается только к GitHub Releases после отдельного решения пользователя.

Отдельно пользователь может включить минимальную статистику версии. Не чаще раза в 24 часа она отправляет только случайный псевдоним установки, текущую версию Impuls и, когда она корректно известна, предыдущую версию. Содержимое Impuls, персональные и аппаратные идентификаторы не отправляются. Без согласия или без настроенного владельцем HTTPS-коллектора запросов нет.

Центр обратной связи в Impuls формирует отчёт локально. Только после явного действия пользователя системный браузер открывает публичный GitHub issue; встроенной отправки, фоновой аналитики и сохранения черновика на сервере нет.
