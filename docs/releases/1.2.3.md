# Impuls 1.2.3

Обновление развивает локальные файловые инструменты «Полки» и делает массовую
обработку предсказуемой.

- OCR, конвертация PNG/JPEG/HEIC, уменьшение и удаление фона работают с группой
  выделенных изображений;
- во время групповой операции показывается прогресс и итоговое количество
  обработанных и пропущенных файлов;
- распознанный текст с нескольких изображений копируется одним блоком с именами
  исходных файлов;
- добавлены «Выбрать все» и системный «Быстрый просмотр» одного или нескольких
  файлов;
- последнюю операцию создания файлов можно отменить: неизменённые результаты
  перемещаются в Корзину и удаляются с полки;
- безопасное переименование также можно отменить, если исходное имя файла
  осталось свободным;
- Impuls отказывается удалять созданный файл, если после операции он был изменён
  или заменён пользователем.

Все OCR- и файловые операции по-прежнему выполняются локально. Оригиналы не
перезаписываются, новые сетевые API и системные разрешения не добавлены.

Публичная сборка пока подписана ad-hoc и не нотаризована Apple, поэтому первый
запуск на другом Mac может потребовать ручного подтверждения Gatekeeper.

---

Impuls 1.2.3 adds batch OCR, conversion, reduction and background removal to the
shelf, with progress reporting, Quick Look, Select All, and conservative Undo
for generated files and renames. Generated results are moved to the Trash only
if they remain unchanged. The update adds no network API or system permission.
