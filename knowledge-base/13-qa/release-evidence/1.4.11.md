# Release QA Evidence — 1.4.11

## Evidence status

This is a **retrospective baseline**, created after 1.4.11 had already shipped and after the release-specific QA evidence system was introduced.

The repository did not preserve a release-time, scenario-by-scenario hardware/TCC record for 1.4.11. This document therefore does **not** convert prior screenshots, conversations, ordinary CI or later testing into invented release evidence. Rows without durable release-specific proof are marked `not-recorded`.

Known deterministic tests and CI remain valid engineering evidence for their automated contracts, but this file is intentionally limited to the manual/mixed portion of the Behavioral QA Matrix.

## Known gaps

- 1.4.11 predates the enforced release evidence system, so manual/hardware/TCC certification cannot be reconstructed honestly from repository history alone.
- This does not mean the scenarios failed; it means release-specific evidence was not preserved in the required form.
- Future releases must not use this historical exception.

## Release decision rationale

`retrospective` is intentionally used because 1.4.11 was already released before this evidence format existed. The record establishes the baseline without claiming certification that cannot be proven.
