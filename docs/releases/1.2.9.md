# Impuls 1.2.9

Последняя переходная установка перед встроенными обновлениями.

- добавлен Sparkle 2.9.5 с закреплённой версией и ревизией;
- команда «Проверить обновления…» теперь использует подписанный канал внутри
  приложения вместо перехода на страницу GitHub;
- feed и ZIP-архив подписываются отдельным ключом Ed25519;
- подпись проверяется до распаковки, а ошибка подписи блокирует обновление;
- после подтверждения Impuls сам скачивает обновление во временное хранилище,
  закрывается, заменяет приложение, запускается снова и очищает временные файлы;
- папка «Загрузки» в штатном сценарии больше не используется;
- решение о сетевом доступе из 1.2.8 переносится без повторного вопроса;
- автоматическое скачивание, тихая установка и отправка системного профиля
  отключены;
- для первой установки на Mac всё ещё требуется ручное разрешение Gatekeeper,
  пока не получены Developer ID и нотаризация Apple.

Версию 1.2.9 необходимо установить вручную последний раз. Полный пользовательский
цикл встроенного обновления будет подтверждён переходом 1.2.9 → 1.2.10.

---

Impuls 1.2.9 is the final transition release before in-app updates. It embeds
Sparkle 2.9.5, uses a fixed signed GitHub Release feed, verifies the Ed25519
signature before extraction, installs only after explicit user action, relaunches
the app, and cleans temporary update files. Existing network-consent decisions
are migrated. Automatic downloads, unattended installation, and system profiling
remain disabled. The first installation on a Mac still requires Gatekeeper
approval until Developer ID signing and notarization are available.
