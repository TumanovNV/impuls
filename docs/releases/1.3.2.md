# Impuls 1.3.2

Перевод больше не заперт в паре «русский — английский».

- язык выбирается прямо в заголовке колонки: заголовок и раньше называл язык,
  теперь он же позволяет его сменить. Отдельной строки управления в панели у
  «чёлки» нет — для неё там нет места;
- доступны все языки, которые умеет переводчик macOS; региональные варианты
  свёрнуты в один пункт, потому что панель предлагает языки, а не локали;
- в меню видно, что будет при выборе. macOS переводит пару, а не язык, и почти
  все её пары идут через английский: русский и немецкий поддерживаются оба, но
  друг в друга не переводятся. Поэтому состояний три — язык готов, пакет надо
  скачать, пара невозможна. Последние показаны серыми, а не спрятаны: важно,
  что язык рассмотрели, а не что его нет;
- направление по-прежнему определяется по алфавиту введённого текста, но теперь
  для любой пары с разными письменностями, а не только для кириллицы с
  латиницей. Алфавит считается по большинству символов, поэтому русская фраза с
  английским названием внутри остаётся русской;
- когда обе стороны пишутся одинаково — немецкий с английским, русский с
  украинским — читать направление не из чего, поэтому пара сохраняет заданный
  порядок, а поменять стороны можно пунктом «Поменять языки местами»;
- выбранная пара сохраняется между запусками;
- по умолчанию по-прежнему русский и английский, так что у тех, кто ничего не
  менял, ничего не изменится.

Предложение поступило через встроенную обратную связь: issue #24.

---

Impuls 1.3.2 lets the translator use any language pair macOS supports, chosen
from the column heading that already named it. Direction is still read from the
alphabet of what you type — now for any pair written differently, decided by
majority so a quoted foreign word does not flip the direction. Pairs written in
one alphabet keep a stated order and can be swapped by hand. The menu marks
which language packs are already downloaded. The default stays Russian and
English, and the choice persists between launches.
