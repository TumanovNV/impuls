# Impuls

*Русский · [English](README.md)*

Impuls — нативная утилита для macOS. Она превращает область вокруг «чёлки»
MacBook — либо компактный язычок у верхней кромки других Mac — в локальный
центр действий, плеер, полку файлов, историю буфера обмена, заготовки,
календарь, переводчик и заметки.

> Публичные сборки пока подписаны ad-hoc и не нотаризованы Apple, поэтому macOS
> требует ручного разрешения Gatekeeper. Доверенная автоматическая установка
> останется отключённой до настройки Developer ID и нотаризации.

## Конфиденциальность

- нет аналитики, телеметрии, рекламы и идентификации устройства;
- нет сетевых подключений без явного разрешения пользователя на проверку обновлений;
- проверка обращается только к GitHub Releases проекта Impuls;
- обновление не скачивается без действия пользователя;
- буфер обмена, заметки, заготовки, файлы и календарь не отправляются с Mac;
- скрытые записи менеджеров паролей не попадают в историю;
- нет private MediaRemote API, запуска `/usr/bin/perl`, внедрения библиотек и
  скрытого helper-процесса.

Точные границы описаны в [PRIVACY.md](PRIVACY.md) и [SECURITY.md](SECURITY.md).

## Impuls Actions

В Impuls 1.2 появился единый локальный поиск по истории буфера, заготовкам и
заметкам. Глобальная горячая клавиша сразу открывает Actions; стрелки вверх и
вниз выбирают результат, `Enter` копирует его, а панель команд позволяет
сохранить текст в заготовки, создать заметку, перевести текст, открыть ссылку
или файл и показать файл в Finder. Индекс строится из действующих локальных
хранилищ, не отправляется в сеть и не сохраняется как отдельная база данных.

В Impuls 1.2.1 добавлены закрепление записей, контекстные действия для ссылок,
адресов электронной почты, телефонов и JSON, пауза мониторинга, срок хранения и
исключения для выбранных приложений. По умолчанию история по-прежнему остаётся
только в памяти. Опциональное сохранение между запусками шифрует локальный архив
с помощью AES-GCM, а случайный ключ хранит в системной Связке ключей macOS.

## Файловые инструменты

В Impuls 1.2.2 на «Полке» появились локальные файловые операции. Изображения
можно конвертировать в PNG, JPEG или HEIC, уменьшать до выбранного размера,
объединять в многостраничный PDF, распознавать на них текст и удалять фон через
Apple Vision. Также доступны AirDrop, системное меню «Поделиться», копирование
пути и безопасное переименование. Любое преобразование создаёт рядом с
исходником новый файл с уникальным именем; оригинал не перезаписывается и не
отправляется в сеть.

В Impuls 1.2.3 эти операции работают и с группой выделенных изображений. Для
долгих серий показывается прогресс, доступен системный «Быстрый просмотр», а
последнее создание файлов или переименование можно безопасно отменить. Impuls
перемещает созданные результаты в Корзину только если они не изменялись после
операции; изменённый пользователем файл приложение не трогает.

## Стабильность и обратная связь

Impuls 1.2.7 удерживает открытую наведением панель на всё время работы
контекстного меню, включая вложенные инструменты для изображений. После закрытия
меню снова действует обычная логика наведения — без оторванных подменю и
визуальных артефактов.

Стабилизационные улучшения 1.2.6 сохраняются: строки интерфейса и локальный поиск
используют ограниченные текстовые представления, запись скриншотов и заметок
вынесена с UI-потока, запросы к плеерам объединяются, обложки уменьшаются до
экранного размера, а поиск ссылок в календаре имеет явный вычислительный лимит.
Перед отменой файловой операции Impuls теперь сверяет SHA-256 содержимого.

Из меню или настроек можно открыть центр обратной связи: сообщить о проблеме,
предложить улучшение или оставить общую оценку. Отчёт формируется локально и
показывается до отправки. Технические сведения опциональны и ограничены версией
Impuls, macOS и архитектурой процессора. Содержимое буфера, заметки, файлы,
пути, календарь, логи и идентификаторы устройства не добавляются. Impuls сам
ничего не загружает — только по явному действию копирует отчёт и открывает
публичную форму GitHub в системном браузере.

Формы репозитория используют те же ключевые поля — раздел, частоту, оценку и
версию; свободные неструктурированные issues отключены. Это делает добровольные
обращения пригодными для приоритизации без добавления аналитики в приложение.

## Настройки и управление с клавиатуры

В нативном окне настроек можно выбрать
глобальную горячую клавишу, режим наведения, размер панели, рабочий экран,
видимые модули и их порядок. После открытия с клавиатуры стрелки влево и вправо
переключают модули, а `Esc` закрывает панель. Настройки, заготовки и заметки
можно экспортировать в локальную JSON-копию и восстановить из неё.

## Управление музыкой

Для Apple Music и Spotify доступны метаданные, перемотка, обложка при наличии и
кнопки управления через их публичные сценарные интерфейсы. Для остальных
плееров и вкладок браузера Impuls может отправлять стандартные медиаклавиши,
если macOS предоставит требуемое разрешение Accessibility. Публичного API,
который показывает полные данные любого системного источника Now Playing, Apple
не предоставляет.

## Требования

- macOS 15 или новее;
- Swift 6 для сборки из исходного кода.

На Mac без физической «чёлки» используется язычок 96 × 10 pt и зона наведения
120 × 16 pt. На MacBook геометрия определяется по safe area дисплея.

## Сборка

```bash
swift test -c release
./Scripts/bundle.sh release
open build/Impuls.app
```

При наличии переменной `IMPULS_DEVELOPER_ID_APPLICATION` скрипт использует
Developer ID. Без неё создаётся ad-hoc сборка, которой на другом Mac потребуется
ручное разрешение Gatekeeper.

## Обновления

При первом запуске Impuls один раз спрашивает разрешение проверять GitHub
Releases. При выборе «Работать без интернета» запросы не выполняются. Решение
можно изменить в меню. Пока нет Developer ID и нотаризации, безопасное действие
открывает страницу релиза для ручной установки; автоматическая установка внутри
приложения намеренно отключена.
