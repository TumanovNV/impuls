# Impuls 1.2.1

Обновление развивает историю буфера и Impuls Actions без добавления сетевых
подключений или новых системных разрешений.

- записи буфера можно закреплять; закреплённые элементы не удаляются по сроку хранения;
- очистка истории сохраняет закреплённые элементы;
- Impuls распознаёт обычный текст, ссылки, email, телефоны, цвета, JSON, код, файлы и изображения;
- Actions предлагает контекстные команды: открыть ссылку, создать письмо, начать звонок, форматировать JSON, закрепить или открепить запись;
- мониторинг буфера можно временно приостановить;
- в настройках можно исключить выбранные приложения из истории буфера;
- доступны сроки хранения от одного часа до 30 дней;
- сохранение истории между запусками включается отдельно и по умолчанию выключено;
- сохранённая история шифруется AES-GCM, случайный 256-битный ключ хранится в Связке ключей macOS;
- старые настройки и резервные копии версий 1.1 и 1.2 остаются совместимыми;
- содержимое истории буфера не включается в экспортируемую JSON-копию.

Скрытые записи менеджеров паролей по-прежнему не попадают в историю. Поиск,
классификация, шифрование и все контекстные действия выполняются локально.

Публичная сборка пока подписана ad-hoc и не нотаризована Apple, поэтому первый
запуск на другом Mac может потребовать ручного подтверждения Gatekeeper.

---

Impuls 1.2.1 adds pinned clipboard entries, content-aware Actions, pause and
retention controls, per-application exclusions, and opt-in encrypted history.
Persistence remains disabled by default; when enabled, the AES-GCM archive key
is stored in macOS Keychain. Clipboard content is never added to JSON backups or
sent over the network.
