# Release QA Evidence — 1.4.13

## Evidence status

This record covers the 1.4.13 patch candidate built from the hardening work merged through PR #66. The PR's automated Swift and Python suites and both GitHub Actions workflows passed. The release owner also completed a manual smoke test of the current hardening build on a real Mac and reported that the application worked correctly.

The smoke report did not identify a fresh-install state, exact hardware/macOS details, TCC reset state, external-device topology, multiple displays or specific service scenarios. It is therefore retained as real release-level acceptance evidence without being converted into scenario-specific passes that were not actually recorded.

Developer ID signing and Apple notarization were not performed. The release uses the repository's existing ad-hoc distribution path and does not claim Apple notarization.

## Known gaps

- The release-owner smoke test confirms that the current hardening build launches and works on a real Mac, but it does not certify the separate hardware, TCC, display, power, update or external-service scenarios above.
- All unperformed manual and mixed scenarios remain explicit `not-run`; green automated tests and CI do not upgrade them to `pass`.
- Developer ID signing and Apple notarization are not available for this release. The existing ad-hoc distribution limitations remain.

## Release decision rationale

`ship-with-known-gaps` is intentional. PR #66 completed the audited security, performance and reliability remediation with green automated validation, and the release owner accepted the current build in a real-Mac smoke test. The remaining scenario-specific manual/hardware/TCC/service checks are visible gaps rather than invented passes, so the evidence policy permits shipping without claiming full certification.
