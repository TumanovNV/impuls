# Impuls 1.3.0

Музыкальный модуль полностью переработан вокруг явного выбора источника.

- источник выбирается непосредственно во вкладке «Музыка»;
- нативный адаптер Apple Music больше не смешан с логикой Spotify и использует
  два пути метаданных: сценарный интерфейс и события самого плеера;
- вместо ложного состояния «Ничего не играет» показываются отдельные причины:
  приложение не открыто, трек не запущен, требуется разрешение или данные не
  удалось прочитать;
- добавлены официальные веб-версии Яндекс Музыки, VK Музыки, YouTube Music и
  Spotify в отдельном системном окне WebKit;
- Яндекс Музыка стоит первой среди веб-сервисов как основной сценарий для
  пользователей в России;
- название, исполнитель, альбом, состояние, длительность и позиция веб-трека
  поступают из ограниченного локального мостика Media Session;
- кнопки play/pause, назад, вперёд и перемотка работают с выбранным веб-плеером;
- выбор источника остаётся локальным: WebKit и сетевое подключение создаются
  только после явной кнопки «Открыть веб-плеер»;
- Impuls не использует неофициальный API Яндекс Музыки, не получает токены,
  не обходит подписку, DRM или региональные ограничения;
- разрешение «Универсальный доступ» музыкальному модулю больше не требуется;
  «Автоматизация» используется только для приложения Apple Music;
- сохранены идентификатор приложения, URL appcast, публичный Ed25519-ключ и все
  правила подписанного обновления Sparkle.

Веб-сервисы могут менять разметку и правила воспроизведения независимо от
Impuls. Базовым источником метаданных служит стандартный Media Session, а
селекторы кнопок используются только как совместимый резервный путь.

---

Impuls 1.3.0 rebuilds Music around an explicit source picker. Apple Music now
has a dedicated native adapter with scripting and player-event metadata paths.
Yandex Music, VK Music, YouTube Music, and Spotify run through their official
sites in a user-opened system WebKit window, with bounded Media Session metadata
and local transport controls. Source selection performs no request; networking
starts only after Open Web Player. The update identity and signed Sparkle trust
chain are unchanged.
