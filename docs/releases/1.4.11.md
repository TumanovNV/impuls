# Impuls 1.4.11

## Первое знакомство и Menu Bar

- Новый полноэкранный по смыслу, но компактный нативный тур знакомит с реальными
  модулями Impuls, Menu Bar, быстрыми действиями, разрешениями и добровольной
  статистикой версии. Он показывается только на чистой установке; при обновлении
  доступна короткая заметка «Что нового», а полный тур можно открыть снова из
  «Настройки → Menu Bar».
- Menu Bar стал настраиваемым рабочим пространством: выберите пресет, режим
  статусного элемента, основной и второй виджеты, приоритеты Smart и до четырёх
  быстрых действий. Фиксированный подвал содержит только открытие панели,
  настройки, проверку обновлений, обратную связь и выход.
- Виджеты используют только уже доступные локальные источники: Mac battery,
  явно включённые Apple devices и выбранный плеер. При отсутствии честного
  значения применяется предсказуемый fallback, без выдуманных процентов,
  идентификаторов, новых разрешений, таймеров или сетевых запросов.

Настройки рабочего пространства сохраняются и входят в резервную копию. Выбор
конкретного устройства остаётся локальным для Mac, потому что его непрозрачный
ключ намеренно не переносится между компьютерами.

# Impuls 1.4.11

## Guided start and Menu Bar

- A compact native tour introduces real Impuls modules, the Menu Bar, quick
  actions, permissions, and voluntary version statistics. It appears only on a
  fresh install; updates see a concise What’s New note, and the complete tour
  can be reopened from Settings → Menu Bar.
- The Menu Bar is now a configurable workspace: select a preset, status-item
  mode, primary and secondary widgets, Smart priorities, and up to four quick
  actions. Its fixed footer contains only Open Panel, Settings, Check for
  Updates, Feedback, and Quit.
- Widgets consume existing local state only: Mac battery, explicitly enabled
  Apple devices, and the selected player. Missing data follows a predictable
  fallback without invented percentages, identifiers, new permissions, timers,
  or network requests.

Workspace choices persist and travel in a backup. A physical-device selection
remains local to its Mac because its opaque key is deliberately not portable.
