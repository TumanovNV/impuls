# Impuls

*Русский · [English](README.md)*

Impuls — нативная утилита для macOS. Она превращает область вокруг «чёлки»
MacBook — либо компактный язычок у верхней кромки других Mac — в плеер, полку
файлов, историю буфера обмена, заготовки, календарь, переводчик и заметки.

> Публичные сборки пока подписаны ad-hoc и не нотаризованы Apple, поэтому macOS
> требует ручного разрешения Gatekeeper. Доверенная автоматическая установка
> останется отключённой до настройки Developer ID и нотаризации.

## Конфиденциальность

- нет аналитики, телеметрии, рекламы и идентификации устройства;
- нет сетевых подключений без явного разрешения пользователя на проверку обновлений;
- проверка обращается только к GitHub Releases проекта Impuls;
- обновление не скачивается без действия пользователя;
- буфер обмена, заметки, заготовки, файлы и календарь не отправляются с Mac;
- скрытые записи менеджеров паролей не попадают в историю;
- нет private MediaRemote API, запуска `/usr/bin/perl`, внедрения библиотек и
  скрытого helper-процесса.

Точные границы описаны в [PRIVACY.md](PRIVACY.md) и [SECURITY.md](SECURITY.md).

## Настройки и управление с клавиатуры

В Impuls 1.1 появилось отдельное нативное окно настроек. В нём можно выбрать
глобальную горячую клавишу, режим наведения, размер панели, рабочий экран,
видимые модули и их порядок. После открытия с клавиатуры стрелки влево и вправо
переключают модули, а `Esc` закрывает панель. Настройки, заготовки и заметки
можно экспортировать в локальную JSON-копию и восстановить из неё.

## Управление музыкой

Для Apple Music и Spotify доступны метаданные, перемотка, обложка при наличии и
кнопки управления через их публичные сценарные интерфейсы. Для остальных
плееров и вкладок браузера Impuls может отправлять стандартные медиаклавиши,
если macOS предоставит требуемое разрешение Accessibility. Публичного API,
который показывает полные данные любого системного источника Now Playing, Apple
не предоставляет.

## Требования

- macOS 15 или новее;
- Swift 6 для сборки из исходного кода.

На Mac без физической «чёлки» используется язычок 96 × 10 pt и зона наведения
120 × 16 pt. На MacBook геометрия определяется по safe area дисплея.

## Сборка

```bash
swift test -c release
./Scripts/bundle.sh release
open build/Impuls.app
```

При наличии переменной `IMPULS_DEVELOPER_ID_APPLICATION` скрипт использует
Developer ID. Без неё создаётся ad-hoc сборка, которой на другом Mac потребуется
ручное разрешение Gatekeeper.

## Обновления

При первом запуске Impuls один раз спрашивает разрешение проверять GitHub
Releases. При выборе «Работать без интернета» запросы не выполняются. Решение
можно изменить в меню. Пока нет Developer ID и нотаризации, безопасное действие
открывает страницу релиза для ручной установки; автоматическая установка внутри
приложения намеренно отключена.
