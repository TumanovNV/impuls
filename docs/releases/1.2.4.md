# Impuls 1.2.4

Стабилизационный релиз усиливает надёжность приложения и создаёт прозрачный
канал обратной связи перед следующим этапом продуктовой разработки.

- в меню и настройках появился центр обратной связи с тремя категориями:
  проблема, предложение и общее впечатление;
- отчёт имеет единую структуру для аналитики, формируется локально и полностью
  показывается пользователю до перехода в GitHub;
- опциональный технический блок содержит только версию Impuls, версию macOS и
  архитектуру процессора;
- Impuls не добавляет в отчёт буфер обмена, заметки, имена и пути файлов,
  календарь, логи, серийные номера или идентификаторы устройства;
- отчёт не отправляется приложением: только по явному действию он копируется в
  буфер, после чего системный браузер открывает фиксированную публичную форму
  GitHub;
- добавлены структурированные GitHub-формы для проблем, идей и общего отзыва;
  сообщения об уязвимостях направляются в отдельный приватный канал;
- полноразмерная обработка проверяет количество пикселей до декомпрессии и
  отклоняет изображение, способное вызвать чрезмерный расход памяти;
- чрезмерно большие тексты и изображения из буфера не сохраняются в историю;
- проверка обновлений использует изолированную сессию без cookies и кэша,
  блокирует параллельные запросы, ограничивает размер ответа и не следует на
  посторонний адрес;
- исправлена передача JPEG и HEIC через буфер: формат больше не объявляется
  как TIFF ошибочно;
- Core Image context переиспользуется при пакетном удалении фона, уменьшая
  накладные расходы между файлами.

Новые разрешения, фоновая аналитика, телеметрия и сетевые API для обратной
связи не добавлены. Публичная сборка пока подписана ad-hoc и не нотаризована
Apple, поэтому первый запуск может потребовать ручного подтверждения Gatekeeper.

---

Impuls 1.2.4 is a stability and feedback release. It adds an explicit,
user-reviewed GitHub feedback report without in-app upload or telemetry,
hardens update checks, bounds clipboard and image processing workloads, fixes
JPEG/HEIC pasteboard declarations, and reuses the Core Image context for batch
work. No new system permission or background analytics is introduced.
