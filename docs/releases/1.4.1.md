## Исправления

- Модуль «Аккумулятор / Питание» теперь дополняет данные IOPowerSources показателями доступного аккумуляторного контроллера: текущей и максимальной ёмкостью, расчётной ёмкостью, напряжением, током, температурой и циклами.
- При подключённом питании вместо «Не определено» отображается подтверждённый статус «От адаптера» и мощность адаптера. Тип MagSafe или USB-C не подменяется догадкой: macOS не предоставляет для него надёжного публичного признака.
- Для полностью заряженной батареи показана фактическая текущая мощность (в том числе 0 Вт), а недоступные на конкретном Mac карточки не загромождают интерфейс прочерками.

### Важно

Impuls 1.4.1 распространяется с ad-hoc подписью до оформления Developer ID. macOS может повторно запросить разрешения Календаря и автоматизации после обновления и при следующих обновлениях. Это не влияет на работу функций после выдачи доступа.

## Fixes

- Power monitoring now uses available battery-controller readings as a conservative supplement to IOPowerSources data.
- Connected power is shown as a verified external adapter instead of an unknown connection; MagSafe and USB-C are never guessed.
- This release is ad-hoc signed until Developer ID is available. macOS may request Calendar and automation permissions again after updates.
