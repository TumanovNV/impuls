Impuls — нативная утилита для macOS 15+, которая превращает область вокруг
«чёлки» MacBook — либо компактную панель у верхней кромки других Mac и
дисплеев — в локальное рабочее пространство: Actions, музыка, полка файлов,
история буфера обмена, заготовки, календарь, переводчик, заметки и центр
питания/аккумуляторов.

Текущий продукт поддерживает **7 языков интерфейса**: русский, английский,
немецкий, французский, испанский, упрощённый китайский и японский. По умолчанию
Impuls следует языку macOS. В **Настройки → Основные → Язык интерфейса** можно
выбрать язык вручную; после подтверждения Impuls безопасно перезапускает себя и
применяет выбор без перезагрузки Mac.

Маркетинговый сайт и страницы политики конфиденциальности также опубликованы в
семи статических языковых версиях. Это отдельные от приложения контуры
локализации: совпадение наборов языков проверяется CI, но один набор не считается
доказательством другого.

> Публичные сборки пока распространяются с ad-hoc подписью и не заявляются как
> нотарифицированные Apple. Поэтому первая установка может потребовать ручного
> разрешения Gatekeeper. Встроенные обновления при этом используют независимо
> проверяемую подписанную цепочку Sparkle.

## Конфиденциальность по умолчанию

- нет рекламы, аккаунта, удалённой конфигурации и device fingerprinting;
- сетевые запросы имеют только три установленных владельца: согласованные
  обновления, явно открытый пользователем Web Music Player и отдельно
  согласованная минимальная статистика версии;
- статистика версии выключена до явного согласия и содержит только случайный
  псевдоним установки, текущую версию и при наличии реально наблюдавшуюся
  предыдущую версию; для одной и той же версии выполняется не более одной
  попытки heartbeat в час;
- содержимое буфера обмена, заметок, заготовок, файлов, календаря, музыки и
  данные eligibility поддержки проекта не входят в telemetry;
- скрытые записи менеджеров паролей исключаются из истории буфера;
- feedback формируется локально и показывается пользователю до действия;
  Impuls сам его не загружает, а по явному нажатию открывает GitHub в браузере;
- project-support prompt считает eligibility только на Mac, не отправляет
  счётчики наружу и автоматически показывается максимум два раза для локального
  состояния;
- нет private MediaRemote API, process injection и скрытого фонового analytics
  SDK.

Точный технический контракт: [PRIVACY.md](PRIVACY.md). Публичная исходная
русская политика: [tumanovnv.github.io/impuls/privacy/](https://tumanovnv.github.io/impuls/privacy/).

## 7 языков

Приложение поставляется с полными таблицами:

- Русский (`ru`)
- English (`en`)
- Deutsch (`de`)
- Français (`fr`)
- Español (`es`)
- 简体中文 (`zh-Hans`)
- 日本語 (`ja`)

Для каждого языка в bundle есть `Localizable.strings` и `InfoPlist.strings`.
CI требует одинаковый набор user-facing ключей во всех таблицах и проверяет
`CFBundleLocalizations`. Язык хранится локально; Impuls не скачивает языковые
пакеты и не отправляет выбранный язык как telemetry.

## Основные возможности

### Actions

Один локальный поиск по истории буфера обмена, заготовкам и заметкам. Глобальная
горячая клавиша открывает Actions напрямую. Клавиатура и мышь разделяют hover,
явный selection и activation: наведение не подменяет выбор. Результат можно
скопировать, сохранить как заготовку/заметку, перевести, открыть как ссылку или
файл и показать в Finder.

### Буфер обмена

История по умолчанию живёт в памяти. Поддерживаются закрепление, пауза,
retention limits и исключения приложений. Опциональное сохранение между
запусками использует локальный AES-GCM архив, а случайный ключ хранится в
macOS Keychain.

### Полка и файловые инструменты

Shelf работает с локальными файлами. Доступны Quick Look, AirDrop/Share,
копирование пути, безопасное переименование, конвертация и resize изображений,
OCR, удаление фона через Apple Vision и создание PDF. Исходник не
перезаписывается и не загружается в облако Impuls.

### Аккумулятор и питание

На MacBook модуль показывает доступные macOS данные об аккумуляторе, зарядке,
расчётном времени, токе/напряжении и адаптере. На Mac mini/Studio/iMac/Mac Pro
он становится модулем **«Питание»** и не выдумывает отсутствующие battery
показатели.

Подключённые Apple-аксессуары могут отображаться из локальных системных данных.
Экспериментальный iPhone/iPad provider работает только при отдельно включённом
контуре и использует уже доверенный macOS device-sync transport; Impuls не
сканирует LAN, не создаёт pairing и не читает контакты/фото/сообщения.

### Музыка

Нативный Apple Music использует разрешённый scripting/notification path. Яндекс
Музыка, VK Музыка и YouTube Music открываются в системном WebKit только после
явной команды **Open Web Player**. Сам выбор источника не создаёт сетевой
запрос.

### Menu Bar и Settings

Menu Bar — presentation surface над уже существующим состоянием, а не новый
provider. Можно выбрать preset, статус, виджеты и быстрые действия. В Settings
настраиваются горячая клавиша, hover, размер/экран панели, модули, Menu Bar,
Apple Devices, privacy choices, язык интерфейса и другие параметры.

### Обратная связь и поддержка проекта

Центр Feedback доступен постоянно. После накопленного реального использования
Impuls может ненавязчиво предложить открыть GitHub проекта или Feedback. Это не
пятизвёздочный рейтинг и не telemetry: eligibility полностью локальна, а
автоматическое предложение ограничено двумя появлениями.

## Обновления

Impuls использует Sparkle 2.9.5. Проверка обновлений выполняется только после
согласия пользователя. Feed и архив подписаны, архив проверяется до распаковки,
а system profiling Sparkle отключён. Update channel и Apple Developer ID /
notarization — разные trust layers: отсутствие Developer ID не является поводом
ослаблять подпись обновлений.

## Системные требования

- macOS 15 или новее;
- Swift 6 toolchain для сборки из исходников.

## Сборка

```bash
swift test -c release
./Scripts/bundle.sh release
open build/Impuls.app
```

`bundle.sh` использует Developer ID, когда настроена переменная
`IMPULS_DEVELOPER_ID_APPLICATION`; иначе создаётся ad-hoc signed build.
