## Known gaps

- `UI-06` is blocked: the final Menu Bar battery light/dark + Retina visual acceptance is still pending because the Computer Use client/server versions do not match.
- The remaining manual/mixed matrix rows were not recorded as release-specific passes for this candidate. Green unit/CI checks do not upgrade them to `pass`.
- Before changing `release_decision` to `certified`, the required real-Mac/TCC/hardware scenarios must be exercised and this record updated with truthful environments/results.

## Release decision rationale

`blocked` is intentional. The PR itself states that a release-specific GUI acceptance remains pending. Keeping the candidate blocked prevents the new evidence system from turning a known missing manual check into an implicit certification.

- Candidate implementation commit before this evidence-only update: `b9902e6e6bb6403b5820a768f587309db91e08e8`.
- PR #51 records 451 Swift tests, 52 Python tests, bundle/codesign checks and production telemetry validation.
- PR #51 also explicitly records the pending light/dark Menu Bar + Retina acceptance; that pending item is the blocking evidence for `UI-06`.
