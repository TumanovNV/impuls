## Исправления и обновления

- Показатель состояния аккумулятора больше не выводится, если macOS отдаёт несовместимые шкалы ёмкости. Это исключает ложные значения вроде 2%.
- В настройках появилась вкладка «Обновления»: можно включить ежедневную проверку подписанного канала Impuls, вручную проверить наличие версии и отдельно выбрать автоматическую установку.
- Без включённой автоустановки новая версия показывается штатным окном с возможностью установить её вручную. При включённой автоустановке проверенный пакет скачивается в фоне и устанавливается при выходе из Impuls.

### Конфиденциальность

Проверка обновлений остаётся добровольной. Impuls обращается только к подписанному каналу обновлений GitHub и не отправляет заметки, буфер обмена, файлы, календарные данные, аналитику, идентификаторы устройства или системный профиль.

## Fixes and updates

- Battery health is hidden when macOS reports incompatible capacity scales, preventing false readings such as 2%.
- Settings now include an Updates tab with daily signed-feed checks, manual checks, and an opt-in automatic installation choice.
- Manual mode presents an update when a release is ready; automatic mode downloads a verified package in the background and installs it when Impuls quits.
