# Impuls 1.2.8

Исправление разделяет наведение, выбор результата и выполнение основной команды
в модуле «Действия».

- наведение мыши теперь только подсвечивает строку и не меняет выбранный
  результат;
- один клик фиксирует выбор без копирования и без запуска другой команды;
- двойной клик сохраняет быстрое основное действие и копирует результат;
- нижняя панель «Копировать», «Открыть», «Показать в Finder», «Закрепить» и
  другие контекстные команды остаётся связана с выбранной строкой, даже когда
  курсор пересекает остальные результаты;
- первоначально выбран первый результат, поэтому к его командам можно перейти
  сразу, без предварительного клика;
- клавиатурная модель не изменилась: стрелки выбирают строку, `Enter` копирует;
- исправление не меняет содержимое буфера, файловые операции, разрешения,
  сетевую границу или телеметрию.

CI отдельно проверяет, что выбор больше не привязан к `onHover`, одиночный клик
назначен выбору, а основная команда требует двойного клика.

---

Impuls 1.2.8 separates hover, selection, and activation in Actions. Hover now
only highlights a row, a single click selects it, and a double-click copies it.
The command bar remains attached to the explicit selection while the pointer
crosses other results, so file actions remain reachable. Keyboard navigation,
privacy boundaries, network behavior, and file-operation semantics are
unchanged.
