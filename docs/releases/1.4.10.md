# Impuls 1.4.10

## Читаемые настройки

Настройки перешли с восьми тесных горизонтальных вкладок на нативную структуру
macOS с боковой панелью и подробной областью. Все восемь разделов полностью
читаются при минимальном размере окна, выбранный раздел и геометрия окна
сохраняются, а навигация работает с клавиатурой и VoiceOver.

## Честная статистика версий

- `Scripts/release-stats.py` показывает GitHub `download_count` DMG-файлов по
  релизам и суммарно, в обычном виде или JSON. Это загрузки ассета, не уникальные
  пользователи и не установки.
- В «Данные и конфиденциальность» появился отдельный добровольный переключатель
  статистики версии. Без согласия запросов нет.
- При согласии и только при настроенном владельцем HTTPS-коллекторе Impuls не
  чаще раза в 24 часа отправляет случайный псевдоним установки, текущую версию и
  корректно известную предыдущую версию. Содержимое и персональные данные не
  отправляются.
- Добавлен развёртываемый first-party collector со строгой схемой, лимитами,
  HMAC идентификатора до записи в SQLite и owner-only отчётом по активным
  согласившимся установкам.

Существующие настройки и данные 1.4.9 сохраняются. Sparkle остаётся закреплён на
версии 2.9.5, а проверка обновлений, веб-плеер и статистика версии остаются тремя
раздельными сетевыми границами.

# Impuls 1.4.10

## Readable Settings

Settings now use a native macOS sidebar and detail layout instead of eight
crowded horizontal tabs. All section names remain readable at the minimum window
size, while the selected section and window frame persist across launches.
Keyboard and VoiceOver navigation are supported.

## Honest version statistics

`Scripts/release-stats.py` reports GitHub DMG asset `download_count` values — not
unique users or installations. A separate version-statistics switch remains off
until the user opts in. With consent and an owner-configured HTTPS collector,
Impuls sends only a random installation pseudonym, the current version, and a
correctly observed previous version at most once per day. A deployable strict
collector HMACs identifiers before SQLite and produces owner-only reports that
are explicitly scoped to consenting active installations.

All 1.4.9 settings and data remain intact. Sparkle stays pinned at 2.9.5, and
updates, web music, and version statistics remain separate network boundaries.
