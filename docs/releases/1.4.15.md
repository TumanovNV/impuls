# Impuls 1.4.15

## Семь языков интерфейса

- Impuls теперь поддерживает 7 языков интерфейса: Русский, English, Deutsch, Français, Español, 简体中文 и 日本語.
- Язык можно выбрать в **Настройки → Основные → Язык интерфейса**.
- После подтверждения смены языка Impuls безопасно перезапускается сам — перезагрузка macOS не требуется.
- Возврат к системному языку снова передаёт выбор macOS.

### О качестве переводов

Русская и английская локализации остаются основными. Переводы пяти новых языков были подготовлены с помощью ИИ и прошли техническую и визуальную проверку, однако пока не проходили полноценную вычитку носителями языка.

В отдельных местах поэтому возможны неточные или неестественные формулировки. Если вы заметили ошибку перевода, пожалуйста, сообщите об этом через **Настройки → Обратная связь** — мы исправим её в следующих обновлениях.

## Поддержка проекта и обратная связь

- После длительного реального использования Impuls может ненавязчиво предложить поддержать проект звездой на GitHub или отправить обратную связь.
- Запрос появляется не при запуске и не во время работы с панелью, а только после накопленного использования и возврата Impuls в спокойное состояние.
- Автоматический запрос ограничен максимум двумя показами для локального состояния приложения.
- Расчёт момента показа выполняется полностью на Mac и не отправляется как телеметрия.
- Постоянные действия **Поддержать проект** и **Отправить обратную связь** доступны в настройках.

## Надёжность

- Решение пользователя по запросу поддержки теперь сохраняется устойчиво даже при жёстком завершении процесса.
- Улучшена документация проекта и навигация для разработчиков и ИИ-агентов.
- Общие улучшения стабильности и совместимости.

# Impuls 1.4.15

## Seven interface languages

- Impuls now supports 7 interface languages: Russian, English, German, French, Spanish, Simplified Chinese, and Japanese.
- The interface language can be selected in **Settings → General → Interface Language**.
- After you confirm a language change, Impuls safely restarts itself — no macOS reboot is required.
- Returning to System Default gives language selection back to macOS.

### Translation quality note

Russian and English remain the primary localizations. The five new translations were prepared with AI assistance and passed technical and visual checks, but they have not yet received a full native-speaker linguistic review.

Some wording may therefore be inaccurate or unnatural. If you notice a translation issue, please report it through **Settings → Feedback** so it can be corrected in a future update.

## Project support and feedback

- After sustained real use, Impuls may occasionally ask whether you would like to support the project with a GitHub star or send feedback.
- The prompt never appears at launch or while you are actively using the panel; it is considered only after accumulated use and a return to idle.
- Automatic prompting is capped at two appearances for the local app state.
- Eligibility is calculated entirely on your Mac and is not transmitted as telemetry.
- Permanent **Support the Project** and **Send Feedback** actions remain available in Settings.

## Reliability

- Project-support decisions are now durably saved even if the process is force-quit.
- Project documentation and AI-agent navigation were improved.
- General stability and compatibility improvements.
