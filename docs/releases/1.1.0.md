# Impuls 1.1.0

Релиз управляемости и надёжности Impuls.

- добавлено отдельное нативное окно настроек;
- появилась глобальная горячая клавиша с несколькими безопасными комбинациями;
- панель поддерживает навигацию между модулями стрелками и закрытие через `Esc`;
- модули можно включать, отключать и располагать в нужном порядке;
- доступны выбор экрана, три размера панели, режим открытия и задержка наведения;
- добавлен единый экран статусов Calendar, Accessibility и будущих уведомлений;
- настройки, заметки и заготовки можно экспортировать и импортировать локальным JSON-файлом;
- код приложения разделён на тестируемое ядро и минимальный launcher;
- CI запускает автоматические тесты настроек и формата резервной копии.

Уведомления в `1.1.0` не запрашиваются: они зарезервированы для напоминаний о
встречах в `1.2`. Impuls по-прежнему не передаёт пользовательские данные по сети.

Публичная сборка пока подписана ad-hoc и не нотаризована Apple, поэтому первый
запуск на другом Mac может потребовать ручного подтверждения Gatekeeper.

---

Impuls 1.1.0 adds a native Settings window, configurable global shortcuts,
keyboard module navigation, module visibility and ordering, display and panel
behaviour controls, permission status, and local JSON backup/restore for
settings, snippets, and notes. The app core now has automated tests. Notification
permission remains unrequested until reminder features arrive in Impuls 1.2.
