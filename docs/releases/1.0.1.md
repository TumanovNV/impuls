# Impuls 1.0.1

Исправляющий выпуск Impuls.

- восстановлен штатный запрос полного доступа к Календарю в macOS;
- в подпись приложения добавлено календарное entitlement-разрешение;
- технические ошибки EventKit теперь показываются отдельно от отказа пользователя;
- из панели можно сразу открыть системные настройки Календаря;
- панель автоматически поддерживает светлое и тёмное оформление macOS;
- все вкладки переведены на адаптивную семантическую палитру;
- приложение и меню-бар получили единый знак «ИМПУЛЬС»;
- CI проверяет entitlement и оба фирменных ресурса в готовом приложении.

## Установка

Откройте `Impuls-1.0.1.dmg`, перетащите Impuls в «Программы» с заменой
предыдущей версии и запустите его. При первом открытии вкладки «Календарь»
macOS должна показать системный запрос доступа.

Сборка пока не нотаризована Apple, поэтому первый запуск может потребовать
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

---

Impuls 1.0.1 restores the macOS Calendar permission flow, distinguishes
EventKit failures from user denial, adds adaptive light/dark panel colours,
and introduces consistent Impuls branding for the app and menu bar.
CI now verifies the Calendar entitlement and both icon resources in the built
application. The build remains ad-hoc signed and is not yet notarized by Apple.
