# Impuls 1.0.0

Первый публичный выпуск Impuls.

- компактная панель для MacBook с физической «чёлкой» и других Mac;
- плеер, полка файлов, история буфера, заготовки, календарь, переводчик и быстрые заметки;
- управление Apple Music и Spotify через публичные интерфейсы macOS;
- стандартные медиаклавиши для других источников;
- явное согласие на сетевую проверку обновлений;
- при отказе приложение не выполняет сетевых запросов;
- удалены private API, внедрение библиотек и скрытый helper-процесс;
- добавлены миграция данных Cyclop, русская и английская локализации.

## Установка

Откройте `Impuls-1.0.0.dmg`, перетащите Impuls в «Программы» и запустите его.
Сборка пока не нотаризована Apple, поэтому первый запуск может потребовать
«Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».

---

This is the first public Impuls release. It includes the compact top panel,
local productivity tools, consent-based update checks, public media controls,
Cyclop data migration, and Russian/English localization. The build is currently
ad-hoc signed and not notarized by Apple.
