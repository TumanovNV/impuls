# Release QA Evidence — 1.4.15

## Evidence status

This record covers the 1.4.15 release candidate built from current `main` after merged PR #75 (seven-language localization and safe self-relaunch) and PR #76 (local-first project-support prompt, durable prompt decisions, QA/documentation routing fixes). The release-preparation diff itself is intentionally narrow: version metadata, user-facing release notes, What's New content and release evidence.

The maintainer manually exercised the new language-selection flow across System, German, French, Spanish, Simplified Chinese, Japanese, Russian and English on a real Mac and reported correct switching/self-relaunch and no blocking layout overflow. The maintainer also manually exercised the project-support prompt flows on a real Mac and reported them working after the durability defect found during QA was fixed. Those observations are preserved as supporting evidence, but the broader current `UI-07` and `SUP-01` matrix rows include additional subconditions that were not all separately recorded, so this release does not stretch partial evidence into a full scenario `pass`.

Developer ID signing and Apple notarization are not claimed here. The repository's release workflow will verify the actual artifact/signature path, Sparkle signing, appcast integrity and launch smoke test before publication.

## Known gaps

- Full native-speaker linguistic review of the five AI-assisted new localizations has not been completed. The interface was technically and visually checked, and this limitation is disclosed in the user-facing release notes.
- The maintainer completed useful manual checks of language switching and the project-support feature, but the current `UI-07` and `SUP-01` matrix contracts are broader than the durable evidence captured; they remain `not-run` rather than being overstated as complete passes.
- Multi-display, fresh-TCC/denied-permission, hardware/power, web-player-service and update-install scenarios were not re-exercised specifically on the version-bumped 1.4.15 candidate.
- Developer ID signing and Apple notarization are not claimed; the release workflow determines and verifies the actual distribution signature path and signed Sparkle feed.

## Release decision rationale

`ship-with-known-gaps` is intentional. PR #75 and PR #76 completed their automated test/CI contours before merge, and the maintainer manually exercised the two new user-facing areas on a real Mac. The release-preparation change does not add new architecture; it packages those already-merged features as 1.4.15. Remaining manual/hardware/TCC/service scenarios stay visible as explicit `not-run` gaps rather than being inferred from green CI or partial manual checks.

## Supporting evidence

- Merged PR #75 added German, French, Spanish, Simplified Chinese and Japanese alongside Russian/English, the in-app language selector and safe automatic self-relaunch. Its CI was green and the maintainer manually checked language switching and layout on a real Mac.
- Merged PR #76 added the local-first project-support prompt, existing-feedback reuse, bounded two-prompt policy and durable decision persistence. Its CI was green; manual testing found and drove the durability fix before merge, after which the maintainer reported the feature working.
- Release base `adcfe2a41f79520722c2bd17ea1ca0fac7fc3473` is the `main` merge of PR #76. Release-preparation candidate commit `597a66877290129b96dae920e122d6204da5201d` contains the 1.4.15 version/notes/What's New/baseline documentation state that this evidence classifies; this file's follow-up metadata commit does not change product behavior.
