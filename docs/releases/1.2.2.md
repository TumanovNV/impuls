# Impuls 1.2.2

Обновление добавляет локальные файловые инструменты в существующую «Полку».

- OCR распознаёт текст на изображении через Apple Vision и копирует результат в буфер;
- изображения конвертируются в PNG, JPEG или HEIC;
- изображения можно уменьшить до 1920, 1280 или 800 пикселей по длинной стороне;
- несколько выделенных изображений объединяются в многостраничный PDF;
- фон удаляется локально через Apple Vision, результат сохраняется как PNG с прозрачностью;
- добавлены AirDrop и системное меню macOS «Поделиться»;
- путь одного или нескольких файлов можно скопировать;
- безопасное переименование сохраняет расширение, запрещает выход из папки и никогда не заменяет существующий файл;
- созданные файлы автоматически добавляются на полку.

Все преобразования создают новый файл с уникальным именем рядом с исходником.
Оригинал не перезаписывается и не удаляется. OCR, обработка изображений и PDF
работают без сети и не требуют новых системных разрешений. Передача файла
начинается только после явного выбора AirDrop или сервиса в меню «Поделиться».

Публичная сборка пока подписана ad-hoc и не нотаризована Apple, поэтому первый
запуск на другом Mac может потребовать ручного подтверждения Gatekeeper.

---

Impuls 1.2.2 adds local file tools to the shelf: Apple Vision OCR and background
removal, PNG/JPEG/HEIC conversion, image reduction, multi-page PDF creation,
AirDrop, the macOS Share menu, path copying, and safe renaming. Every transform
creates a uniquely named file next to the source; originals are never replaced,
deleted, or uploaded. The update adds no network API or system permission.
