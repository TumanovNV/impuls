# Impuls 1.2.0

Релиз объединяет существующие инструменты Impuls в единый локальный рабочий
сценарий.

- добавлен модуль Impuls Actions с поиском по истории буфера, заготовкам и заметкам;
- глобальная горячая клавиша теперь открывает Actions напрямую;
- доступны выбор результата стрелками вверх и вниз и копирование через `Enter`;
- текст можно сохранить в заготовки, перенести в новую заметку или сразу отправить в переводчик;
- ссылки и файлы можно открыть, а файл — дополнительно показать в Finder;
- поиск не зависит от регистра и диакритики и ранжирует точные совпадения выше;
- новый модуль корректно добавляется в существующие настройки, а резервные копии формата `1.1` остаются доступными для импорта;
- добавлены автоматические тесты поиска, источников, команд и миграции порядка модулей.

Impuls Actions не создаёт отдельную поисковую базу: индекс строится из текущих
локальных данных при отображении панели. Запросы, результаты, буфер обмена,
заготовки и заметки не отправляются по сети. Новых системных разрешений версия
`1.2.0` не запрашивает.

Публичная сборка пока подписана ad-hoc и не нотаризована Apple, поэтому первый
запуск на другом Mac может потребовать ручного подтверждения Gatekeeper.

---

Impuls 1.2.0 adds Impuls Actions: one on-device search across clipboard history,
snippets, and notes. The global shortcut opens it directly, keyboard selection
and Enter provide a fast copy path, and contextual commands can create notes,
save snippets, translate text, open links or files, and reveal files in Finder.
The index is ephemeral, adds no network access, and requests no new permission.
