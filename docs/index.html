Меньше микродействий. Больше времени на основную работу.

Impuls не заменяет ваши приложения. Он убирает лишние переходы между ними — когда нужно найти, скопировать, перенести или быстро обработать файл.

01

Верните то, что копировали раньше

Один поиск находит ссылку, реквизиты или команду в истории буфера, заготовках и заметках — даже если вы не помните, где это было.

02

Перенесите файл между приложениями

Положите файлы на полку Impuls и заберите их в нужном окне. Оригиналы остаются на месте.

03

Обработайте изображение локально

Распознайте текст, удалите фон, измените формат или размер, соберите PDF — без загрузки рабочих файлов в онлайн-сервисы.

Модули

Восемь инструментов. Включите только те, которыми пользуетесь.

Настройте состав и порядок модулей под свою работу. Панель открывается наведением или хоткеем, переключается стрелками и закрывается по Esc.

Actions

Один поиск по истории буфера, заготовкам и заметкам с действиями прямо из результата.

Плеер

Apple Music нативно; Яндекс Музыка, VK, YouTube Music и Spotify — через официальные сайты в WebKit.

Полка файлов

Перенос файлов между окнами, OCR, удаление фона, конвертация изображений, PDF, AirDrop и безопасное переименование.

История буфера

Возврат к тому, что скопировали час назад. Скрытые записи менеджеров паролей исключены.

Заготовки

Часто повторяемые тексты и команды — вставляются без поиска по переписке.

Календарь

Ближайшие встречи в поле зрения. Доступ запрашивается системным диалогом macOS.

Переводчик

Быстрый перевод выделенного текста — из панели или прямо из результата Actions.

Заметки

Мысль записывается там же, где вы работаете, без запуска отдельного приложения.

Управление с клавиатуры

Хоткей на выбор из безопасных комбинаций, стрелки между модулями, Esc для закрытия. Мышь не обязательна.

Работает не только на чёлке

Геометрия чёлки определяется по safe area дисплея. На Mac без выреза — компактная вкладка 96×10 pt у верхнего края.

Разрешения по мере надобности

Начиная с 1.2.9, последующие версии устанавливаются внутри Impuls через подписанный канал — без GitHub, DMG и мусора в «Загрузках».

Вопросы

Что обычно спрашивают

У меня Mac без чёлки. Impuls мне подходит?

Да. На таких Mac Impuls показывает компактную вкладку 96×10 pt у верхнего края экрана с областью наведения 120×16 pt. Геометрия чёлки MacBook определяется автоматически по safe area дисплея, поэтому подстраивать ничего не нужно.

Impuls действительно ничего не отправляет?

Без действия пользователя Impuls не подключается к сети. Отдельно можно разрешить подписанные обновления GitHub или нажать «Открыть веб-плеер» для выбранного музыкального сайта. Содержимое буфера, заметок, заготовок, файлов и календаря не передаётся никогда; для веб-сервиса действует его собственная политика.

Почему приложение не из App Store и не нотаризовано?

Публичная сборка пока подписана ad-hoc и не нотаризована Apple, поэтому первая установка требует ручного подтверждения Gatekeeper. Impuls не обходит эту защиту. Начиная с 1.2.9, дальнейшие обновления устанавливаются внутри приложения после проверки подписанного feed и архива; Developer ID уберёт именно первый ручной барьер.

Какие музыкальные источники поддерживает Impuls?

Источник выбирается прямо во вкладке. Apple Music работает через нативный адаптер. Яндекс Музыка, VK Музыка, YouTube Music и Spotify открываются официальными сайтами в отдельном окне WebKit; панель получает ограниченные Media Session-метаданные и управляет страницей. Неофициальные API, токены и private-фреймворки не используются.

Что происходит с моими данными при переустановке?

Настройки, заметки и заготовки экспортируются в локальный JSON-файл и восстанавливаются из него. Резервные копии формата 1.1 читаются версией 1.2 — порядок модулей мигрирует автоматически, новый модуль Actions добавляется в существующую конфигурацию.

Сколько это стоит и можно ли собрать самому?

Бесплатно. Для сборки из исходников нужен Swift 6: swift test -c release, затем ./Scripts/bundle.sh release. Impuls происходит от проекта akalikbergenov/cyclop; MIT-части сохраняют своё уведомление, новый код — под GPL-3.0-or-later.
